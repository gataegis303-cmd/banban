# BanBan 开发交接包（dev-handoff）

> 面向 iOS 开发团队的落地交付物料。生成于设计定稿之后（校验脚本 v22，21 组检查全过）。

## 1. 目的与范围

BanBan 项目现有两份面向不同读者的交付文档：

| 文档 | 读者 | 内容定位 |
| --- | --- | --- |
| `../handoff.md` | 产品 / 设计 / 回顾 | 设计语言综述、页面清单、交互流、已知限制、验证历史（§11） |
| `dev-handoff/`（本目录） | iOS 开发 | 可直接落地的四类物料：Swift 令牌代码、令牌映射总表、组件清单、交互规格、校验闭环使用说明 |

本交接包的**唯一令牌权威来源**是 `../colors_and_type.css`。所有色值、字号、圆角、阴影均从该文件提取，Swift 代码与之逐一对应；CSS 更新后须跟随更新（见第 4 章）。

## 3. 约束与不变项

- **只读资产**：`BanBan.design` 画布、`pages/*.html`（18 页）、`colors_and_type.css`、`generation-tree.json` 是设计阶段的定稿产物。开发期如需视觉或结构调整，应回到设计侧修改后再同步，不要在工程里「顺手改」。
- **深色为默认外观**：18 页 HTML 均为 `<html class="dark">`。Swift 动态色以深色值为默认分支，浅色值取自 CSS `:root`（详见 01 第 4 章级联沿用规则）。
- **令牌单一来源**：`BanBanTokens.swift` 头部注明「勿手改、跟随 CSS 更新」。业务代码只消费令牌，不散落硬编码色值。
- **资产策略**：无真人肖像。原型中的 Unsplash 占位图与 DiceBear 生成头像均为示意，上线实现使用用户上传照片 + 生成头像占位（详见 02 组件清单「头像」条目与 `../handoff.md` §6）。

## 4. 校验闭环约定

本工作区有一套随迭代演进的自动化校验（`/usr/bin/python3 .trae/validate_banban.py`，当前 v22，21 组检查）。设计文件、Swift 令牌锚点、交互总数断言（`== 63`）都在覆盖范围内。

完整运行方式、检查清单与开发期约定（何时跑、失败怎么办、为何禁止删检查凑通过）见 `04-validation-and-loop.md`。
